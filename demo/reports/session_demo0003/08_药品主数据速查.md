## 四、字段说明（数据字典）

| 字段 | 类型 | 说明 |
|---|---|---|
| `drug_id` | INT | 主键，`inventory` 与 `sales_records` 靠它关联 |
| `generic_name` | VARCHAR(100) | 通用名，问数时最主要匹配字段 |
| `brand_name` | VARCHAR(100) | 商品名 / 品牌名，同一通用名可能对应多个品牌 |
| `approval_number` | VARCHAR(50) | 国药准字批准文号，唯一标识一个上市许可 |
| `specifications` | VARCHAR(100) | 规格，如 `0.25g*24粒` |
| `dosage_form` | VARCHAR(50) | 剂型：片剂 / 胶囊剂 / 注射剂 / 散剂 |
| `manufacturer` | VARCHAR(100) | 生产厂家 |
| `therapeutic_area` | VARCHAR(50) | 治疗领域，用于品类结构分析 |
| `description` | TEXT | 适应症等自由文字 |
| `created_at` | TIMESTAMP | 建档时间 |
